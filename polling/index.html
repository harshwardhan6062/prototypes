Four ways to learn something happened

One event. Four delivery mechanisms. Watch what each one costs.

Wire trace

Every message crossing the boundary. ↑ client → server, ↓ server → client.

Raw SSE stream

The literal bytes the server writes. Lines starting : are comments — the server saying “still here, nothing new.” EventSource throws these away, so they never reach your JS.

Cumulative requests

Every HTTP round trip each mechanism has made since the page loaded.
